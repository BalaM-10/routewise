Put a report recorded on real hardware here as `recorded.json` (Runs page > Save report).
The app loads it automatically for visitors whose browser cannot run Gemini Nano.
Only ship reports produced by an actual calibration run.

The `judgeModel` field in a report is the reviewer the run started with. When a reviewer's daily allowance ran out, the next one took over, and each written answer records the model that actually reviewed it.
